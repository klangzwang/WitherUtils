## Version 2.0.0 — A Fresh Start

**WitherUtils 2.0.0** is a complete rewrite from the ground up.
The mod has been rebuilt from scratch with a cleaner codebase, better performance, and a more solid foundation for future content.

> **Important:** This is **not** a continuation of 1.0.x. Old items and blocks will return gradually over time — but this release intentionally starts small and grows from here.

---

## Items

| Item | Description |
|------|-------------|
| **Wrench** | Rotates and configures blocks. Essential tool for any builder or engineer. |
| **Steel Hammer** | Used to interact with the custom Anvil block for crafting steel-based recipes. |
| **Cutter** | Opens a portable cutting interface. Useful for on-the-go crafting. |
| **Soul Bank** *(Basic / Advanced / Ultra)* | Stores souls in three tiers — each tier increases the storage capacity. |

---

## Blocks

### Energy

| Block | Description |
|-------|-------------|
| **Solar Panel** *(Basic / Advanced / Ultra)* | Generates Forge Energy from sunlight. Panels of the same tier connect to form larger arrays. |
| **Creative Generator** | Provides unlimited energy — ideal for testing and creative mode builds. |

### Rack System (Multiblock)

A modular multiblock storage and distribution system:

| Block | Description |
|-------|-------------|
| **Rack Casing** | The structural shell of a rack multiblock. |
| **Energy Controller** | Collects and exports energy stored across the rack structure. |
| **Fluid Controller** | Collects and distributes fluids within a rack multiblock. |
| **Item Controller** | Manages item storage across the connected rack casings. |
| **Terminal** | Interface block to access and manage the contents of a rack system. |

### Utilities and Decoration

| Block | Description |
|-------|-------------|
| **Greenhouse Block** | Accelerates crop growth in its vicinity by simulating ideal growing conditions. |
| **Custom Anvil** | A steel-tier anvil used together with the Steel Hammer for advanced crafting. |
| **Floor Sensor** | A redstone sensor that detects entities walking over it. Configurable via Wrench. |
| **Wall Sensor** | Detects entities or blocks on the wall. Outputs a redstone signal. |
| **Angel Block** | Allows free-floating placement in mid-air — great for scaffolding and building. |
| **Catwalk** | Industrial-style walkway. Supports upper/lower half variants and waterlogging. |
| **Railing** | Decorative and functional metal railing for walkways and platforms. |
| **Steel Beam** | Structural steel beam for industrial builds. |
| **Steel Pole** | Vertical steel pole for factories and scaffolding. |
| **Metal Door** | Heavy industrial door — powered and controllable. |
| **Lava Bricks** | Decorative brick block with a fiery appearance. |
| **Sliced Concrete** | A thinner, sliced variant of concrete for detailed builds. |
| **Soul Fire Block** | A decorative block emanating soul fire. |
